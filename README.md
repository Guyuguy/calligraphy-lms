# 硬笔书法教学管理系统

一套面向硬笔书法培训机构的教学管理系统，涵盖课程推荐、课程安排、学生/教师/课程管理、学习进度查看、教学进度管理。

## 设计参考

- **Moodle** — 课程活动类型、作业批阅、成绩册
- **Canvas LMS** — 模块化课程结构、学习分析仪表盘
- **Open edX** — 序列化课程单元、进度可视化
- **Gibbon** — 学生档案、教师排课、出勤
- **Frappe Education** — 班级、课程计划、学生分组
- **Cal.com** — 教师预约时段、冲突检测

## 技术栈

- **后端**：Hono + Bun + 内存数据库（MVP 阶段）
- **前端**：React 19 + Vite + Radix UI + Tailwind v4
- **设计系统**：复用 RCS warm stone 主题（Claude Orange `#c96442`）

## 启动方式

```bash
# 安装依赖
bun install

# 启动后端（端口 3001）
bun run server

# 另开终端启动前端（端口 5173）
cd web && bunx vite
```

浏览器访问 http://localhost:5173
